FAQ

More in the user guide FAQ.

macOS says the app is "damaged"?

It isn't — that's Gatekeeper blocking an un-notarized app. Move it to Applications, run xattr -cr /Applications/Miyo.app, then right-click → Open.

Windows SmartScreen warning?

Click "More info → Run anyway". The installer has no code-signing certificate yet — normal for open-source apps.

Environment variables look garbled?

The data-dir master.key was lost. Restore from a backup JSON (Settings → Restore).

MCP reports spawn ENOENT?

The binary isn't on PATH. Since v0.0.10 use the absolute path inside the install bundle (see the agent section above), not a bare miyo-mcp.

Dev build can't see release data?

Expected: dev builds use the isolated Miyo-dev directory. Move data via backup JSON.

How do I report a problem?

The top-bar "Feedback" button generates a local diagnostics report — attach it to a GitHub Issue.
